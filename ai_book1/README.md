# 山仍在

## 从怀疑到选择

从熟悉的生活出发，追问我们为什么相信、为什么怀疑，以及怎样在没有终极保证时作出选择。

**[阅读全文](山仍在-全书.md)**

这版依据[大纲1.md](../大纲1.md)及已经调整的问题顺序展开，保留[大纲.md](../大纲.md)中意义、自由与受缚的主线。正文包含序、三部十五章、间奏和终章，另附阅读札记与出处。

语言尽量简明。先从学校、饭桌、工作、承诺等具体事情进入，再解释所需的概念。原典位置和引申范围放在书后，连续阅读时可以暂时略过脚注。
