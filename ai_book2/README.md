## 综合与精简

采用 `book1` 的三部结构，纳入 `book` 对无限追问、有限理由、信念与决定、重复劳动和受缚的论证。西西弗斯单独成章，三重看山贯穿首尾。

每章集中处理一个问题，开头直接提出判断，随后展开理由。生活情境通常只留一个主要例子，删去反复换例、重复总结与章节预告；必要的概念区别保留在正文，较详细的原典定位放在书后。

分章文件与全文版内容一致。修改分章后，应同步更新全文版；全文版的注释直接跳转到其中的书后札记。
