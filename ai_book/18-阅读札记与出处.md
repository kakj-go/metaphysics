# 阅读札记与出处

相关作品按章、节或命题编号定位，以便跨中译本查阅。各条同时区分原典观点与引申解释。外文段落主要作意译与概述；除明确标出的短语，不应作为现成中译本的逐字引文使用。

<a id="note-01"></a>

## 一　看山的三重境界

见普济编《五灯会元》卷十七“吉州青原惟信禅师”条。原文从“见山是山”说到“见山不是山”，最后说“依前见山只是山”。“看山还是山，看山不是山，看山依旧是山”是转述，并非古籍原句。以它描写未经反省、经历怀疑与重新进入生活之间的变化，属于借喻，不是对禅宗修证的完整解释。原文还继续询问三种见解的同异，并未止于三句口号。

可核对：[《五灯会元》卷十七原文](https://www.shidianguji.com/zh/book/JS1818/chapter/1m6lgx82rwzsk)、[青原惟信条原文摘录](https://www.fodizi.tw/f04/42115.html)。

<a id="note-02"></a>

## 二　苏格拉底与尼采的批评

苏格拉底对审视生活的强调，可参看柏拉图《申辩》38a附近。尼采对苏格拉底的集中批评，见《偶像的黄昏》“苏格拉底问题”。正文没有将“欧洲虚无主义始于苏格拉底”作为尼采的逐字引文，也没有把尼采对理性主义、道德和生命的批评化约为反对发问。

可核对：[《申辩》英文文本](https://www.gutenberg.org/cache/epub/1656/pg1656-images.html)、[《偶像的黄昏》英文文本](https://www.gutenberg.org/files/52263/old/old/52263-h/52263-h.htm)。

<a id="note-03"></a>

## 三　能指与所指

参看索绪尔《普通语言学教程》第一编第一章“语言符号的性质”。应当区分声音形象、概念与现实中的对象。符号的任意性涉及能指与所指之间没有天然必然的联系，并不意味着一个人可以任意更改公共语言。

可核对：[法文第一编](https://fr.wikisource.org/wiki/Cours_de_linguistique_g%C3%A9n%C3%A9rale/Premi%C3%A8re_partie)、[英文选段](https://www.flf.vu.lt/dokumentai/Saussure_Course-85-98.pdf)。

<a id="note-04"></a>

## 四　拉康与意义的关系

参看拉康《无意识中文字的动因，或自弗洛伊德以来的理性》，收入《文集》。该篇不同译本的标题有差异。能指的关系参与意义形成，不等于“只有能指，没有所指”。“懂事”等日常例子属于引申，并非取自拉康原文。

可核对：[该文英文文本](https://web.english.upenn.edu/~cavitch/pdf-library/Lacan_Insistence_of_the_Letter_in_the_Unconscious.pdf)。

<a id="note-05"></a>

## 五　语言游戏与使用

参看维特根斯坦《哲学研究》第一部分第7、23、43节；概念边界与家族相似可继续阅读第65—71节。第43节关于意义与使用的说明有适用范围，不是关于所有意义的一句无条件定义。语言游戏也没有“其前提一律不得寻找”的规则。正文将删减桌腿的问题用于讨论模糊边界；它与忒修斯之船所涉及的历时同一性有关联，但不是同一个问题。

可核对：[《哲学研究》德文文本](https://wittgensteinproject.org/w/index.php/Philosophische_Untersuchungen)。

<a id="note-06"></a>

## 六　事实、事物与沉默

参看维特根斯坦《逻辑哲学论》1.1、2、2.01及第7命题。事实与事物的区分，并不直接等于运动与静止的区分。该书对可说与不可说的处理属于早期思想语境，不能直接与后期语言游戏拼成一套未经说明的论证。

可核对：[《逻辑哲学论》德英对照文本](https://www.gutenberg.org/ebooks/5740)。

<a id="note-07"></a>

## 七　休谟的归纳问题

参看《人类理解研究》第四节、第五节和第七节，分别涉及经验推理的疑难、习惯及必然联系的观念。经验可靠性与逻辑必然性应当区分；休谟的问题不能直接解释成因果不存在。游戏居民、修灯与道歉的例子用于考察解释层次，并非休谟的原例。

可核对：[第四节](https://davidhume.org/texts/e/4)、[全书目录及分节文本](https://davidhume.org/texts/e/)。

<a id="note-08"></a>

## 八　康德的二律背反与立法

参看《纯粹理性批判》“纯粹理性的二律背反”第一组，标准页码A426/B454起；关于知性作为自然的立法者，可参看A126及B163—165附近。二律背反是在康德自身的先验哲学中提出并处理的问题，正文只介绍其问题方向，不声称复现全部证明。这里的自然立法也不等于个人能够凭愿望设定自然事实。

可核对：[《纯粹理性批判》英文文本](https://www.gutenberg.org/cache/epub/4280/pg4280.html)。

<a id="note-09"></a>

## 九　视角主义

参看尼采《道德谱系》第三篇第12节。由认识具有位置，进一步探讨证据、交流和权力，属于引申。“没有真理，只有语言游戏”不能当作尼采原句；视角不同也不足以免除事实判断的责任。

可核对：[《道德谱系》英文文本](https://www.gutenberg.org/files/52319/52319-h/52319-h.htm)。

<a id="note-10"></a>

## 十　理发师的条件

正文采用理发师悖论的通俗形式，并明确理发师本人属于规则所涉及的群体。推论是不存在同时满足全部条件的理发师。“有一位这样的理发师”这一存在假设应当被撤回，不能将矛盾转嫁成现实世界的普遍性质。此处的分析可以直接由正文给出的条件检查，不依赖哲学家的权威。

<a id="note-11"></a>

## 十一　不完备定理的范围

参看哥德尔1931年论文《论〈数学原理〉及相关系统中的形式不可判定命题Ⅰ》。关于第一不完备定理，采用的是包含后续加强结果的通行表述，不能将其中“一致性即可”的措辞直接当作1931年原始证明的逐字条件。定理针对满足特定条件的形式理论；第二不完备定理还涉及一致性陈述及其形式化方式。这些定理不能推出世界自相矛盾，社会制度也不能直接等同于算术理论。

可核对：[1931年论文扫描及书目信息](https://commons.wikimedia.org/wiki/File:%C3%9Cber_formal_unentscheidbare_S%C3%A4tze_der_Principia_Mathematica_und_verwandter_Systeme_I.pdf)。

<a id="note-12"></a>

## 十二　缸中之脑

可参看普特南《理性、真理与历史》第一章“缸中之脑”。普特南的处理牵涉指称问题；正文没有复述或宣称解决他的反怀疑论论证，只用这一设想区分“提出一种经验之外的可能”与“掌握其现实证据”。“无法站到缸外”本身不够构成完整的反驳。

作品定位：[出版社第一章页面](https://www.cambridge.org/core/books/abs/reason-truth-and-history/brains-in-a-vat/4301D7FCC5869697D0110E89CAA1A47B)。该页面提供书目信息与开篇内容，完整论证仍需阅读原书。

<a id="note-13"></a>

## 十三　克尔凯郭尔的信仰

参看《恐惧与战栗》，尤其“问题一”“问题二”。该书以约翰内斯·德·西伦提奥的笔名写成，叙述声音不宜简单等同于一段作者直接发布的教义。“信仰之跃”是常见的概括说法。宗教语境中的信仰问题与日常生活中的有限承诺需要区分；关于照顾、决定和责任的推论属于另外的引申。

可核对：[英文选译文本](https://en.wikisource.org/wiki/Selections_from_the_writings_of_Kierkegaard/Fear_and_Trembling)。

<a id="note-14"></a>

## 十四　三变形、权力意志与超人

参看《查拉图斯特拉如是说》第一部“精神三变”、第二部“自我超越”，以及“序言”关于超人的部分。以此理解学习、拒绝、创造和自我改变，是一种引申；三变形不宜当作固定的人生阶段，权力意志也不能等同于单纯的意志力。尼采的价值排序及其与平等观念的关系仍需结合其他作品考察，关于相互照顾与平等参与的主张不应全数归给他。

可核对：[《查拉图斯特拉如是说》英文文本](https://www.gutenberg.org/cache/epub/1998/pg1998.txt)。

<a id="note-15"></a>

## 十五　永恒轮回

参看《快乐的科学》第341节“最大的重负”；第276节可作为理解爱命运的一处参照。将第341节作为思想实验来理解，不等于宇宙循环已经被科学证明。关于日常重复、照顾劳动以及不应要求创痛原样重来的判断，属于伦理上的引申，不能直接归于尼采。

可核对：[《快乐的科学》英文文本](https://web.stanford.edu/~jsabol/existentialism/materials/nietzsche-gay-science.pdf)。

<a id="note-16"></a>

## 十六　社会关系与实践

参看马克思《关于费尔巴哈的提纲》第1、2、3、6、11条。人的现实存在涉及物质生活与社会关系，不能化约为符号游戏；实践也不意味着停止解释。值班表是另设的情境，关于参与、证据和修改的论证也并非马克思的原文。“正、反、合”不能当作马克思提供的普遍历史公式。

可核对：[《关于费尔巴哈的提纲》英文文本](https://www.marxists.org/archive/marx/works/1845/theses/theses.htm)、[版本说明](https://www.marxists.org/archive/marx/works/1845/theses/)。

<a id="note-17"></a>

## 十七　加缪与西西弗斯

参看《西西弗斯神话》第一部分“哲学上的自杀”及末篇“西西弗斯神话”。加缪对信仰跳跃抱有警惕；荒诞涉及人与世界的关系性冲突，不能等同于逻辑矛盾。关于劳动分担、休息和改变制度的推论，是从寓言回到现实所作的延伸。西西弗斯幸福的说法采用意译，未逐字引用某一中译本。

可核对：[《西西弗斯神话及其他随笔》英文文本](https://files.blogs.baruch.cuny.edu/wp-content/blogs.dir/2205/files/2012/10/Albert-Camus-The-Myth-of-Sisyphus.pdf)。
