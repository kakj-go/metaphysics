# 序　问题开始的时候

生活里的事情大多有目的，人生却未必因此有了答案。工作为了收入，收入为了生活；再问生活为了什么，原来顺畅的解释便停住了。

使人不安的，往往是这一停顿。我们希望有一个最后的理由，让今天的付出、过去的失去和未来的选择，都能得到交代。这个理由迟迟没有出现，眼前的一切便开始显得可疑。

可是，终极答案的缺席，为什么应当取消有限的价值？一次帮助不能挽救所有人，它仍可能改变一个人的处境。一段关系不会永远持续，其中发生过的关心仍然有分量。只有永恒才值得，这个要求本身也需要理由。

看山是山，看山不是山，看山还是山。[〔1〕](#note-01) 起初，我们接受熟悉的解释；后来，看见解释的条件与遗漏；再后来，带着这些认识重新生活。山没有获得最终的证明，人却不必因此一直站在路外。

走哪条路，仍要决定。选择使一些可能性关闭，也让另一些可能性成为现实。人开始有了愿意投入的事情，同时受到它们的要求。

困难就在这里：怎样在不确定中相信，在约束中保有自由，在有限的一生中形成值得承担的生活。

# 第一部　看山是山　我们如何相信


<a id="sec-01"></a>

# 第一章　意义从哪里来

意义最初来自我们接受的生活。什么值得追求，什么令人羞愧，怎样才算成功，这些判断往往在受到审查以前，就已经开始引导我们。

一个把优秀当作自身价值的人，取得成绩后仍不敢休息。每次比较都可能证明他还不够好。目标不断提高，安心却始终没有到来，因为那个标准只告诉他怎样继续，从未告诉他何时足够。

追问从这里开始：我为什么接受这个标准？它满足了什么需要，又使我付出了什么？一个判断来自家庭或社会，既不能证明它正确，也不能证明它错误。来历让它成为可以检查的东西。

但追问也可能陷入另一种苛刻。工作要由幸福证明，幸福要由人生证明，人生又要由宇宙证明。只要没有找到最后的根据，前面的理由就全部作废。我们尚未证明生活无意义，已经先规定了只有绝对的意义才算意义。

苏格拉底式的追问使未经检查的确信暴露出来。尼采对苏格拉底的批评，则让理性作为生活裁判的地位也受到审查。[〔2〕](#note-02) 这两种力量都值得保留：要求价值交出理由，也要求我们说明，为什么只接受某一种理由。

因而需要分清：眼下要解决什么，需要什么样的根据。谋生的理由、长期投入的理由和宇宙存在的理由，不能由同一个答案包办。后一种尚未得到回答，前两种仍然可以被认真讨论。

有限的理由也要经受检查。某种生活让谁受益，代价落在谁身上，是否容许受影响的人提出异议。这些问题能够帮助判断一种价值是否值得继续；单凭它不能保证永恒，还不足以把它取消。

意义可以有条件，也可以改变。开始思考，便是把继承来的方向逐一辨认，让其中值得保留的部分得到理由，让不再值得的部分失去支配生活的权力。


<a id="sec-02"></a>

# 第二章　我们怎样认识世界

认识世界，已经包含了对世界的整理。我们区分对象、性质和关系，才能说清某件东西是什么，发生了怎样的变化。

亚里士多德在《范畴篇》中讨论这些基本的区别。康德进一步追问：互不相同的感觉，怎样能够成为关于对象的经验？在他的理论中，时间、空间与知性的范畴，是经验得以形成的认识条件。[〔3〕](#note-03)

二者的问题和答案各有背景，却共同提醒我们注意：看见某种东西，与理解自己看见了什么，并非可以完全分开的两件事。对象进入认识时，我们已经在使用区分，建立联系。

一个人把一次失败说成“我是失败者”，便把行动的结果变成了整个人的性质。那次失败可能真实，也可能严重；但从这里推到他的一切能力、所有关系和整个未来，还缺少许多理由。概念帮助他说明处境，也可能过早替处境作了判决。

这种整理常在不知不觉中进行。我们以为只是如实描述，实际上已经决定了哪些差别重要，哪些可以略过。反省认识，需要把这些决定重新看见，检查它们是否适合对象。

康德所说的“为自然立法”，涉及经验秩序的认识条件。这些条件有其普遍性要求，不能简单等同于个人的偏好。一个人改变看法，并不能凭愿望改变自然事实。认识参与对象如何被理解，仍然要接受经验的限制。

因此，理解有条件，知识也可以可靠。我们能够比较判断，发现遗漏，让新的经验纠正原先的分类。完全掌握对象的愿望很难满足，知道它的一些方面却是可以推进的工作。

最初的“看山是山”，便依靠这种信任：名字能够指向对象，经验能够增加理解。反省使信任看见自己的条件，从而知道什么时候可以继续使用，什么时候需要修改。


<a id="sec-03"></a>

# 第三章　完整解释的诱惑

人希望理解整体，因为孤立的事实很难说明自己。一个事件怎样发生，常要放回它与其他事件的关系里才能看清。

黑格尔重视这种联系，也关注固定的规定怎样显出自身的限度，推动思考继续发展。辩证法由此关心变化中的关系；把一个观点与相反观点各取一半，还没有触及这种运动。他的绝对精神涉及艺术、宗教与哲学中的自我认识，属于其体系的主张。[〔4〕](#note-04)

另一种整体可以在生命游戏中看见。方格按简单而确定的规则变化，却能形成移动、闪烁和复杂的图案。整体形态要在格子之间的联系中理解。规则是否确定，与结果是否容易预测，是两个问题。

完整解释的诱惑，出现在我们希望这些差别最终全部消失的时候。一旦掌握最根本的规则，仿佛就能说明每一种经验，连痛苦也会在整体中获得安排好的位置。

然而，说明一件事为什么发生，并没有同时说明它值得发生。历史原因可以解释一项损失，损失仍然由具体的人承担。整体增加了理解，却不能仅凭自己更大，就免除对局部遭遇的回应。

体系也会因追求完整而失去判断力。如果成功证明它，失败也证明它，任何反对都只说明反对者尚未理解，那么现实便没有办法迫使它修改。容纳所有说法，与真正解释事情，表面上可能十分相像。

一个解释值得使用，是因为它确实说明了什么。它还应说清什么经验可能使它改变。暂时留下无法解释的部分，能够让认识继续；为了维持完整而把那些部分删掉，反而使整体越来越远离它要理解的世界。

# 第二部　看山不是山　确定性怎样松动


<a id="sec-04"></a>

# 第四章　经验为何不能保证未来

过去反复如此，可以成为相信未来的理由，却不能单靠逻辑保证未来必定如此。休谟的归纳问题，追问的正是经验怎样支持尚未发生的事情。[〔5〕](#note-05)

如果说经验推断值得相信，因为它过去一直成功，就已经在使用那个需要说明的推断：过去的成功将延续到未来。增加观察可以提高可靠程度，却没有把这一步变成绝不可能相反的逻辑必然。

按下开关，灯亮了。反复的经验使我们形成预期。灯有一天不亮，我们便检查线路、电源和灯泡。这个过程显示了经验的作用：它支持判断，也让异常成为重新检查的理由。

两件事先后出现，还不足以认定其中存在因果。判断因果需要比较条件，排除其他解释，并在可能时考察干预的结果。休谟提出认识上的疑难，并没有因此证明因果关系不存在。

习惯让人无需每次从头论证便能行动，也可能使已经变化的情形继续被按旧方式理解。认识因而需要保留两个能力：依据已有经验形成稳定的安排，发现条件变化时重新判断。

人容易在这里提出过高的要求：既然判断会错，那么一切相信都是盲信。但错误的可能仍有大小，证据仍有强弱。一个经过反复检查的解释，与一个任意猜测的解释，可以具有不同的可信度。

还要分清因果与价值。知道一项负担怎样形成，有助于找到改变它的办法；是否应当继续承担，则涉及人的需要、责任和实际后果。更多原因并不会自动给出最终目的。

未来没有被过去封住，人仍可以合理地准备未来。我们可以根据充分的理由行动，给意外留下余地，并在变化出现时修正。这样获得的可靠性有限，却已经足以支持许多值得进行的工作。


<a id="sec-05"></a>

# 第五章　理性的边界

一段推理正确，结论仍然依赖前提。理性的工作既要检查推理，也要检查前提从哪里来、适用于什么对象。

康德把这种检查带到知识的条件中。我们认识的是在感性形式与知性范畴下出现的对象，不能直接把这些认识推广为对象脱离一切认识条件时的样子。物自体与现象的区分，要求人看清这个限度。[〔6〕](#note-06)

当问题涉及世界整体，限度便尤其明显。世界有时间上的开端，还是没有开端？康德在第一组二律背反中并置两方的论证，检查理性把世界整体当作经验对象加以规定时产生的困难。

推理发生冲突，可以促使人审查共同的设定。两边都显得有理由，还不足以宣布现实在同一意义上同时符合两个互相排斥的结论。一个问句能够写出来，也需要说明其中的概念怎样适用于对象。

知识的限度还需要具体辨认。有时缺少材料，继续调查可能有所帮助；有时问题含糊，需要澄清表达；有时方法本身有适用范围。把这些情形全称为不可知，会使本来可以继续的工作过早停止。

对自由的讨论也需要这种谨慎。规律、决定论与可预测性并非同一个概念。一个过程难以预测，未必完全偶然；一个结果完全偶然，也未必更受人的掌握。自由还涉及理由、能力和强迫，不能仅凭宇宙有序或无序作出判决。

理性走到边界，仍能说明为什么停下。这种自我约束使未知保留为未知，也让继续研究有了明确的方向。愿望可以推动思考，获得结论仍然需要相应的根据。


<a id="sec-06"></a>

# 第六章　系统为何不能包办一切

清楚的规则能够解决许多问题，但“规则清楚”还不足以保证“所有问题都能解决”。条件冲突、证明的限度与算法的限度，需要分别理解。[〔7〕](#note-07)

设一位属于村中男子的理发师，他给村里所有且只给那些不自己刮脸的男子刮脸。他是否给自己刮脸？给，就违反只给不自己刮脸者刮脸的条件；不给，又落入应当由他刮脸的范围。两种答案都冲突。

结论是不存在满足这些条件的理发师。写下一套条件，并不能保证它所描述的对象存在。这里需要撤回的是不相容的设定。

哥德尔不完备定理处理另一种问题。采用包含后续加强结果的通行表述：一致、能有效列举公理且足以表达基本算术的形式理论，会有在其中既不能证明、也不能反驳的命题。不完备涉及证明能力，一致性涉及是否会推出矛盾，两者应当分开。

停机问题又涉及算法。不存在一个总会在有限时间内给出正确答案的通用程序，能够判断任意程序在任意输入下是否停止。这一结论仍然允许我们判断大量具体程序；受到排除的是对全部情况的通用保证。

这些结果各有严格的条件，不能合并成“世界必然自相矛盾”。把数学结论用于社会或人生，还需要新的理由。一个制度可能遗漏人的需要，但制度并不因此直接等同于满足定理条件的算术理论。

对生活而言，应当检查一套规则怎样面对自己未能处理的情况。它可以补充调查，允许申诉和修改；也可能宣布凡是不在规则里出现的事情，都不值得考虑。后一种做法让工具取得了筛除现实的权力。

可靠的系统需要说清自己的范围。能说明一部分，已经可以有用；遇到限度以后，仍要容许问题被准确提出。完整的许诺不能替代这项工作。


<a id="sec-07"></a>

# 第七章　语言如何改变问题

语言使事情能够被说出来，也参与了事情怎样被理解。一个名字保存了某些区别，同时可能使其他区别暂时消失。

索绪尔区分能指与所指，分别涉及声音形象与概念。概念又不同于现实中的对象。维特根斯坦的语言游戏则让人注意，词语怎样在描述、请求、许诺等活动中使用。[〔8〕](#note-08)

一张桌子逐渐失去支撑，到哪一步不再是桌子？修理的人可以继续把它当作等待修好的桌子，回收的人则按材料处理它。边缘情形需要说明用法；常见情形里的交流，仍然能够相当准确。

意义因而需要放回活动中理解。名字怎样指认，话语怎样起作用，误解以后怎样纠正，都参与了语言的可靠性。一个词没有预先划定所有边界，使用它的人也并非因此什么都不知道。

提问同样会借用熟悉的形式。“人生的用途是什么”，用了询问工具的方式。工具有制作时规定的用途，人是否也应当按这一方式理解，还需要理由。语法顺畅，有时会遮住这个尚未得到说明的跨越。

“生活没有意义”也可能涉及不同的困难：目标失去吸引力，关系断裂，长期疲惫，或对终极目的的怀疑。把问题展开，回应才能接近困难。澄清语言要与理解处境一起进行，否则只纠正词语，痛苦仍留在原处。

语言也不能独自取消现实。把强迫叫作奉献，负担仍然由人承担。需要检查名称怎样影响安排，以及安排实际造成了什么。对词语的批判只有回到这些关系，才可能扩大理解。

我们仍然可以使用爱、责任和自由。使用时要愿意说明它们涉及哪些行动、允许哪些期待，又给谁留下表达的空间。词语经过检查以后，更有可能准确地承载生活。


<a id="sec-08"></a>

# 第八章　视角与真理

认识总从某个位置开始。我们关心的问题、使用的工具和所处的生活，决定了什么首先进入视野。一个完全取消位置的观察者，很难同时保有观察的条件。

尼采的视角主义让这种条件受到检查。认识可以通过更多观看方式增加理解，也要反省哪些情感与利益参与了解释。[〔9〕](#note-09) 视角因此使交流成为必要：一个人遗漏的部分，可能正是另一个人每天面对的事情。

同一项工作安排，管理者看见进度提高，工作人员看见休息减少。两种描述可能都说出了事实。要形成判断，需要把收益与代价一起放进讨论，检查怎样分配，又有哪些后果尚未被听见。

只说双方视角不同，还没有处理权力的差别。一个人能把自己的判断写进规则，另一个人只能承担规则的后果。让不同经验得到表达，需要实际的机会；将所有声音简单并列，也可能遮住这种不平衡。

但位置有别，不会使说法同样可靠。事实、证据和推理仍能限制解释。谁愿意面对反例，谁能够说明更多内容，谁在遗漏被指出后进行修正，都会影响判断的可信度。坚定的语气无法完成这些检查。

价值的来历可以揭示它为何受到维护。它是否值得继续接受，还要检查理由与后果。发现一个观念的历史条件，尚未完成对它的否定。

共同讨论未必获得一致，却能让一个判断面对自身经验以外的东西。暂时无法共同确认的部分，可以继续调查，也可以保留争议。把未知立刻填成自己喜欢的答案，会使视角再次冒充全部事实。

求真需要承认位置，又要求说法对对象负责。看见得有限，是继续听取、观察和纠正的理由。一个视角能否改变自己，比它是否自称已经看穿一切，更能说明它认识世界的能力。


<a id="sec-09"></a>

# 第九章　我自己从哪里来

怀疑外部的标准以后，人常想找回真正的自己。但我们表达愿望的语言、感到羞愧的习惯和判断价值的方式，也都在与别人相处时形成。

福柯考察知识、分类与权力怎样参与主体的形成。“人之死”涉及现代知识中一种人的形象及其历史条件。拉康则从语言与无意识进入自我问题，指出我们说出的理由未必穷尽欲望。[〔10〕](#note-10) 二者的问题不同，都让现成的自我说明变得值得检查。

一个长期被称作懂事的人，可能在别人提出要求以前就答应。他以为自己喜欢帮助别人，后来却发现，拒绝使他恐惧，因为失去赞许仿佛就失去了自身价值。外部的要求已经能够用他的声音说话。

这种发现不会自动证明他的善意虚假。关心、恐惧和期待认可，可以同时参与行动。若只有毫无影响的愿望才算真实，我们很难保留任何愿望。应当继续辨认的是：理解这些成分以后，他仍愿意做什么，能够承担多少。

自我因此也在行动中形成。改变一次回应，表达一个从未说出的限度，可能使人获得新的经验。过去的习惯仍有力量，但已经出现过的不同做法，可以成为继续改变的材料。

改变需要条件。一个人能否拒绝，取决于拒绝以后会失去什么，是否有支持和其他选择。同样的劝告落在不同处境里，可能要求完全不同的代价。理解自己，还需要理解行动空间怎样受到限制。

我们无法回到一个没有任何来历的起点，也不必把过去的一切判成错误。已经形成的能力与关系，是现在能够开始的条件。其中一些需要保留，另一些需要重新安排。

“成为自己”于是可以理解为持续参与自身的形成：看清哪些要求正在支配行动，辨认哪些值得接受，并让新的选择进入生活。自我未必先于这些选择完整存在，它也会在选择及其后果中获得形状。


<a id="sec-10"></a>

# 间奏　自由的眩晕

旧的标准失效，会留下方向的空缺。我们知道不愿怎样生活，却还不知道愿意把时间交给什么。摆脱命令与形成行动能力，需要不同的工作。

虚无可以描写这种处境：原先的价值失去力量，新的方向尚未形成。它也可能与疲惫、失去和缺少支持有关。精神上的清醒，未必已经带来实际的选择空间。

始终保持距离，可以避免一些失望，却不能保存一份尚未使用的人生。时间仍会过去，关系仍因回应或沉默而改变。悬置判断有时必要，也需要面对自身的后果。

决定需要理由，理由却无法提前经历决定之后的生活。有些不确定能通过调查减少，有些只有投入以后才会发生变化。开始一件事情，便是让自己的判断进入现实。

克尔凯郭尔在宗教语境中讨论信仰的决断，加缪则警惕借信仰跳跃消除荒诞。[〔11〕](#note-11) 这项分歧应当保留。日常承诺可以帮助理解决断的风险，却不能把不同思想都归成“随便相信即可”。

一项值得承担的信念，需要足以支持投入的理由，也需要容许经验纠正它。真诚无法保证正确，冒险无法独自证明价值。人愿意开始，还要愿意说明结果与最初的判断有什么距离。

我们未必能够立刻选定一生。有时先需要休息和帮助，有时可以尝试一件能够承担的事。疑问仍在，生活已经有了可以回应的部分。


<a id="part-03"></a>

# 第三部　看山还是山　选择与承担


<a id="sec-11"></a>

# 第十章　西西弗斯下山的时候

西西弗斯的石头会滚落。他知道，仍要下山重新开始。失去最后的完成，是否也就失去了每一次努力的分量？

加缪把注意力放在这种清醒中。荒诞发生在人要求世界给出清楚解释与意义、世界却未给予相应回答的关系里。它涉及人的处境，不能当作世界逻辑矛盾的证明。[〔12〕](#note-12)

人常依靠终点理解付出：完成以后便能安定，抵达以后便能真正生活。西西弗斯的故事抽掉了这个保证，逼人看见一个问题：我们是否只肯承认能够永久保存的成果？

许多维持生活的劳动都要重新进行。一次照顾结束，人的需要还会回来；但被照顾的那段时间，已经与独自承受时不同。结果会过去，不能据此把它说成从未产生作用。成果有时就是一段得到妥善对待的时间。

有限的作用仍然需要评价。它是否回应真实的需要，代价由谁承担，是否存在更好的安排。这些理由可以继续争论，却已经有了能够说明和检查的内容。缺少终极保证，不会使一切行动具有相同的分量。

神话中的惩罚被设定为无法取消，现实中的负担却常有能够改变的部分。谁交来这块石头，谁从中获益，是否能够分担或停止，都应当被允许追问。赞美承担的态度，不能代替对承担条件的审查。

加缪在清醒中寻找反抗与生活的可能。从这里回到现实，还需要让态度获得行动的空间。一个疲惫的人可能需要减少负担；他此刻不能感到幸福，也不会因此失去对自身处境提出要求的资格。

西西弗斯下山的时刻，使清醒与继续同时出现在眼前。对现实中的人而言，继续还可以包括改变路线、请求帮助，以及结束本来可以结束的惩罚。承认生命有限，仍有理由使其中的时间过得不同。


<a id="sec-12"></a>

# 第十一章　有限的一生

今天的生活已经是人生的一部分。把它始终当成准备，便可能让真正想过的生活一直停在以后。

海德格尔用此在讨论会理解并关心自身存在的存在方式。人总已经处在世界中，与事物和他人打交道，并朝向可能性生活。被抛与操心，分别涉及这种已有的处境及其存在结构。[〔13〕](#note-13)

我们没有选择最初的条件：出生、身体与已经发生的经历，都不能回到起点重新安排。承认这些条件，能够使行动看清自己的范围。过去也提供了现在能够使用的能力、语言和关系，改变从这些材料中开始。

有限性还包括死亡。一个人无法把所有道路走完，再选择最值得的一条。每次投入都会用去时间，也使其他可能性逐渐远离。向死而在把这种不可替代的限度带到对自身可能性的理解中。

等待并不在生命之外。事情总会增加，条件也很难一次齐全。推迟一项重要的选择，需要检查眼前缺少的条件，也要考虑时间会怎样改变尚未实现的可能。

死亡使时间的有限变得清楚，却不会自动规定怎样的生活更好。值得做什么，仍然需要理由。若把有限性理解为每分钟必须产出成果，只会让休息成为新的负担，连空闲也被要求证明用途。

生活的限度与能够改变的困难，还应分别理解。我们无法实现全部可能，却可以争取更合理的时间安排；无法删除过去，却能重新处理过去对现在的影响。承认有限，可以使行动更准确地找到对象。

成为自己，需要理解愿意接受的生活，并承担它的后果。这也允许学习、迟疑与修正。选择会有遗憾，完美的保证难以获得；我们仍能逐渐认清，有限的时间正在被交给什么，哪些部分值得继续，哪些已经需要改变。


<a id="sec-13"></a>

# 第十二章　从否定到创造

否定能够清出位置，新的生活还需要在这个位置上形成。只知道不愿继续什么，尚未决定愿意开始什么。

尼采以骆驼、狮子和孩子描述精神的三种变形：承担重负，争取说不的自由，重新开始与创造。[〔14〕](#note-14) 这些形象提示了不同的能力。它们可以在一个人的不同处境中同时出现，难以按年龄排成固定的顺序。

承担使能力得以积累，也可能让负担免于审查。人习惯了先问怎样完成，便容易不再问是否值得完成。拒绝打断这个顺序，让要求重新面对理由，也使新的方向获得空间。

但反对仍可能由旧的标准安排生活。一个人时时证明自己比服从者清醒，注意力便依旧围绕被拒绝的东西转动。在能够开始的地方，他还要面对自己的时间：除了反对，我愿意做什么？

孩子象征创造性的肯定。某件事开始值得投入，并不需要等到它获得整个世界的批准。人参与形成做法，让一个愿望逐渐成为能够持续的活动。新的价值在行动中获得内容，也接受行动结果的检查。

这里需要耐心，也需要修改。最初的兴奋会过去，想象与实际会有距离。坚持可以出于充分的理由，也可以出于不敢承认错误。自我超越要求人重新判断力量的方向，不能只按付出更多来衡量。

尼采的权力意志与超人涉及力量、评价和对既有人及价值的超越，不能缩减为日常的意志力。从中讨论自己的选择，是进一步的引申：我所称的进步，扩大了哪些能力，又维持了哪些未经检查的要求？

个人的肯定也要面对他人的生活。愿意承担自己的选择，并没有取得替别人决定代价的权力。创造进入共同关系，便需要回应受影响的人。这样形成的新生活，才可能在投入中继续保有反省，而无需靠拒绝所有反对来维持。


<a id="sec-14"></a>

# 第十三章　如果这一切再来一次

永恒轮回把一个问题带到今天：如果整段生命以同样的次序反复到来，我将怎样面对？尼采在《快乐的科学》第341节提出这个设想。[〔15〕](#note-15)

作为思想实验，它暂时拿走未来补偿现在的许诺，使日常安排本身接受检查。眼前的日子若始终如此，哪些值得保留，哪些已经难以承担？我们宣布重视的东西，是否在实际使用的时间里得到位置？

一个不断把关系放到忙完以后的人，可能发现自己最看重的事一直没有时间。他用未来的相处为今天的疏远解释，未来又不断被新的工作推迟。重复让这种差距显现：真实的安排正在维护另一套轻重。

反复也可以形成价值。学习依靠练习，关系依靠回应。一件事没有始终新鲜，仍可能在持续中增加能力与信任。判断重复，需要看它维持了什么，以及参与的人在其中怎样变化。

有些重复则不断累积伤害。无法商议的负担、没有休息的劳动，不能只因一直存在就获得肯定。值得改变的安排需要实际的余地；要求人从态度上赞同它，无法减少它的代价。

因此，轮回的设想不能成为对受苦者的命令。拒绝创痛再次发生，仍可以愿意继续未来。已经发生的事需要面对，但一个人没有义务把每种伤害都解释成值得热爱的命运。

改变也不必以推翻整个人生开始。它可以先调整一项安排，停止一种习惯，让一件重要的事情重新得到时间。有限的变化会进入此后的重复，使原先被固定的日子出现不同的可能。

思想实验没有替我们决定该保留什么。它使一个通常被忽略的事实变得清楚：生命的大部分发生在反复的日常里。未来值得期待，正在度过的日子也应得到判断，不能永远只作为抵达别处的费用。


<a id="sec-15"></a>

# 第十四章　选择需要共同的条件

理解改变了，生活的条件未必随之改变。一个人看清不合理的要求，仍可能因收入、时间和资源的限制而继续接受。自由因而也要在共同的安排中寻找。

马克思把人的实际活动与社会关系带入思考。认识需要面对实践，人也在现实关系中生活。异化劳动进一步考察劳动者与活动、成果及他人的关系，不能只按一时的工作感受理解。[〔16〕](#note-16)

一张值班表让每个人承担相同次数，看起来公平。实行以后，有人赶不上末班车，有人无法照顾孩子。相同的数量落在不同处境中，形成了不同的负担。修改需要这些差别被听见，也需要受到安排的人有机会参与。

实践让计划遇到原先略去的条件。解释可以帮助找出问题怎样反复形成，行动则让新的安排产生结果。结果仍需判断：效率提高以后，代价由谁承担；抱怨减少以后，是否只是表达已经无效。做过，并不自动等于做对。

改变也需要物质的内容。时间如何分配，成果由谁掌握，谁能够影响决定，都会扩大或压缩行动的空间。把负担换成一个动听的名字，不会使承担者获得休息。

马克思对共产主义不同阶段的讨论，同样涉及生产条件、劳动关系和人的发展。制度的名称不能替代这些条件。希望一种共同生活值得争取，还要说明它怎样运作，怎样处理冲突，并根据结果继续修改。

一项安排以解放为目标，也可能形成新的支配。参与者能否了解情况、提出异议和影响决定，需要检查实际的关系。这些具体要求各有理由，不能仅凭一个宏大的目标免于讨论。

共同实践使个人的问题获得更大的范围：我们需要怎样的条件，才能让更多人有能力选择？其中应有无法按相同贡献计量的人。生活的位置不能只由产出决定；人在不同的时候需要支持，也以不同的方式参与。


<a id="sec-16"></a>

# 第十五章　受缚与自由

选择使生活有了内容，也使人受到所选之事的要求。练习一门手艺需要时间，形成一种能力需要规则。约束在这里关闭某些可能，也使原来做不到的事情成为可能。

“建构通往受缚”说出了投入的代价。接受一种安排，便无法同时保留全部选择。但从受缚推到奴役，还需要检查约束怎样发生：谁提出要求，谁承担代价，谁能够拒绝和修改。

强迫与经过选择的承担可以有不同的结构。有些关系压缩能力，使表达受到惩罚；有些关系提供支持，让人更能行动。只按限制的多少判断自由，会遗漏这些区别。

最初的同意也不能包办所有未来。人会发现当初不了解的条件，身体与需要也会变化。如果一句“你已经答应”能够封住后来的一切问题，自愿的开端便可能成为不能商议的命令。

承诺仍需要可靠性。别人已经根据它安排生活，改变便应说明原因，面对因此产生的损失，尽可能商议交接。责任来自具体的关系，也应与实际的知识、能力和条件相称。

拒绝的能力，使接受更有机会成为真实的接受。一个永远不敢说不的人，可能只是在延续恐惧。能够表达限度，并在拒绝以后保有基本的生活条件，是自由需要共同维护的内容。

讨论并不使关系必然松散。遗漏的困难得到回应，负担重新安排，承诺也可能因此更可靠。另一方面，有些关系持续拒绝回应，结束它便可以成为必要的行动。留下与离开，都需要依据实际的关系判断。

解构能解除未经审查的命令，也可能留下空缺；建构能形成能力与关系，也可能固化为支配。两种工作需要持续回应彼此。自由在其中有了具体的要求：能够选择值得承担的事情，也能够对承担的条件继续提出意见。


<a id="sec-17"></a>

# 终章　山依旧是山

重新看山，未必需要恢复最初的确信。名字仍能使用，经验仍有作用；我们同时知道，任何解释都要在它能够承担的范围内接受检查。

“看山不是山”，让熟悉的世界显出自己的条件。“看山还是山”，则容许有限的事情继续成立。怀疑带来的认识留在这里，也不再替所有事物作出全盘否定的判决。

活着的意义是什么？这个问题仍可继续。但寻找宇宙的最终目的，与辨认值得投入的生活，需要分别面对。一项负担得到分担，一个人获得表达的机会，都已经使具体的生活发生变化。这些变化可以成为继续行动的理由。

它们未必永远保存，认真也不保证结果如愿。有限的意义需要维护，需要接受反驳，并在失败以后重新判断。生命没有因此免于失去，却有了可以参与形成的方向。

自由也在这样的生活中获得内容：能够拒绝，能够投入，能够在条件变化时商议和修改。选择带来约束，约束仍应面对参与者的需要与意见。

山不会替人决定路线。人可以承认尚未知道的部分，看清愿意承担的事情，然后迈出自己能够迈出的那一步。

## 1　看山

普济编《五灯会元》卷十七“吉州青原惟信禅师”条。三重看山的常见说法是转述，原文末段说“依前见山只是山”。以它讨论接受、怀疑和重新生活，属于借喻；既不完整解释禅宗修证，也不规定人人必经的阶段。

## 2　追问

柏拉图《申辩》38a附近；尼采《偶像的黄昏》“苏格拉底问题”。审视生活与对理性主义的批评，需要分别理解。不能把尼采的批评简化为反对发问，也不宜将“虚无主义始于苏格拉底”作为未经定位的逐字引文。

## 3　分类与认识

<a id="note-04"></a>

## 4　整体与涌现

黑格尔《哲学全书·逻辑学》第1—12、79—82节；《哲学全书·精神哲学》第553节起。辩证法不能化为普遍适用的“正、反、合”程序。生命游戏参看Martin Gardner于1970年10月发表的介绍。确定的局部规则可产生复杂形态，不能由此证明自由、无规律或黑格尔的体系。

<a id="note-05"></a>

## 5　经验与因果

休谟《人类理解研究》第四、第五、第七节，分别涉及经验推理、习惯和必然联系。归纳的根据、认识因果的方法与因果是否存在，属于需要区分的问题。关于因果与人生价值的讨论，是进一步的论证。

<a id="note-06"></a>

## 6　理性的限度

康德《纯粹理性批判》“现象与本体的区分”“纯粹理性的二律背反”；第一组从A426/B454附近开始。物自体不限于暂时没有观察到的东西。二律背反应放在康德的先验哲学中理解，不能直接用作世界自相矛盾的证明。

<a id="note-07"></a>

## 7　系统的三种限度

理发师的结论可由给定条件直接检查。哥德尔1931年《论〈数学原理〉及相关系统中的形式不可判定命题Ⅰ》是原始出处；正文采用包含后续加强结果的通行表述。图灵1936年《论可计算数及其在判定问题上的应用》奠定相关不可判定性结果，停机问题采用现代概述。三者不可直接推广为社会定律。

<a id="note-08"></a>

## 8　语言

索绪尔《普通语言学教程》第一编第一章；维特根斯坦《哲学研究》第一部分第7、23、43及65—71节。第43节对意义与使用的说明有适用范围。桌子的边缘情形用于讨论概念用法，不等于完整复述家族相似或历时同一性问题。

<a id="note-09"></a>

## 9　视角

尼采《道德谱系》第三篇第12节。通过多种视角增加理解，是相关问题的入口。关于事实检验、表达机会和权力差别的讨论，另有论证责任，不能全数归于这一节的原意。

<a id="note-10"></a>

## 10　自我与主体

福柯《词与物》第九、十章及《主体与权力》；拉康《无意识中文字的动因，或自弗洛伊德以来的理性》，标题有不同中译。福柯的“人之死”涉及知识中人的形象；拉康强调能指关系，也不等于否认意义和现实。懂事者的情境是引申说明，未构成对具体人的精神分析。

<a id="note-11"></a>

## 11　信仰与决断

克尔凯郭尔《恐惧与战栗》“问题一”“问题二”；加缪《西西弗斯神话》“哲学上的自杀”。前者以笔名写作，叙述声音应结合文本理解；后者对信仰跳跃抱有警惕。将日常承诺与它们比较，不表示两种立场能够合并。

<a id="note-12"></a>

## 12　荒诞与西西弗斯

加缪《西西弗斯神话》“荒诞的自由”及末篇“西西弗斯神话”。荒诞涉及人与世界的关系。关于照顾劳动、负担分担和改变现实惩罚的判断，是从寓言回到生活后的延伸，不能当作加缪已给出的制度方案。

<a id="note-13"></a>

## 13　有限的存在

海德格尔《存在与时间》第9、12—18、29、41、50—53节，涉及此在、在世存在、被抛、操心与向死而在。操心属于存在结构，本真也不能直接等同于道德上的好。有关休息与生活安排的判断，是进一步的引申。

<a id="note-14"></a>

## 14　创造与自我超越

尼采《查拉图斯特拉如是说》第一部“精神三变”、第二部“自我超越”及“序言”关于超人的部分。三变形不能当作固定的人生年表，权力意志也不限于意志力。关于共同商议与回应他人的要求，应与尼采本人的价值排序分别理解。

<a id="note-15"></a>

## 15　永恒轮回

尼采《快乐的科学》第341节；爱命运可参看第276节。这里使用思想实验的读法，未将它当成宇宙循环的科学结论。关于创痛、改变日常与拒绝伤害重演的判断，是伦理上的引申。

<a id="note-16"></a>

## 16　实践与共同条件

马克思《关于费尔巴哈的提纲》第1、2、3、6、11条；《1844年经济学哲学手稿》“异化劳动”；《哥达纲领批判》第一部分关于共产主义社会不同阶段的讨论。实践、异化与社会关系各有具体内容。有关参与、异议和规则修改的要求，是进一步的制度判断。
